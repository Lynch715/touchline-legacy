## 发布内容

- 以单文件 v3 WebP 导航版为基础，资源内嵌，无构建步骤。
- 手机底栏两排各 9 个入口；历史、数据、说明与队徽合并到“其他”。
- 浏览器自动存档，并支持 JSON 文件导入和导出。升级或更换地址前，请先导出旧存档，再在新地址导入。
- 制作人：大老师；鸣谢：蜡笔小屁新；制作人微信：lynchrrr。

将 `index.html` 用 HTTP 服务器提供即可游玩。此仓库仅包含发布文件，不包含开发测试存档。
